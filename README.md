# Equity in Post-HCT Survival Predictions

Course project exploring survival prediction after hematopoietic cell transplantation (HCT), with an emphasis on equitable model performance across patient groups.

## Methods

- Kaplan-Meier and Cox proportional-hazards analysis
- XGBoost and CatBoost
- DeepSurv and graph neural network experiments
- Data preprocessing, feature selection, and subgroup fairness analysis

## Contents

The repository includes the consolidated DSCI 521 analysis, supporting experiment notebooks, competition data, the project report, presentation, and proposal.

> Educational data-science project only. It is not a validated clinical tool and should not be used for diagnosis or treatment decisions.
